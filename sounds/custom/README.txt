Put your own sound files here to replace the built-in ones (any of: .wav .aiff .caf .m4a .mp3).
File names the card looks for:

  open    the card appears
  move    the cursor moves to another quest (hover, up/down)
  scroll  the quest list scrolls by about one row
  select  open a quest or the board
  done    a quest is cleared
  undo    a change is undone
  cancel  a menu or the detail panel closes without a choice
  track   a quest is tracked (the slot beside it)
  untrack tracking is removed
  close   the card closes

Example: open.wav, move.wav, done.m4a. Missing names keep the built-in sound.
Delete a file to go back to the built-in sound. New cards pick up changes; nothing to rebuild.
